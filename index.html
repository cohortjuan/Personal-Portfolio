Habit Tracker

⭐ Featured

"Most habit apps are overbuilt. This one is a checkbox with memory."

A minimal daily habit tracker with streak calculation and a GitHub-style contribution grid. Built to explore CSS Grid deeply and practice state management without a library.

The Hardest Part

Streak calculation broke when users skipped days then came back. I modelled the data as a Set of ISO date strings rather than a boolean array, then walked backwards from today. Switching the data structure halved the logic complexity.

CSS Layout Lab

Capstone

"An interactive Flexbox/Grid cheat-sheet that explains by doing."

Every Flexbox and Grid property has a live toggle — change a value, see it render instantly. Built for my own learning during the bootcamp, shared because others found it useful.

The Hardest Part

Keeping the preview and code display in sync without a framework required careful DOM management. I used a single state object and a render() function that always rebuilt the UI from scratch — I'd essentially invented one-way data flow before I knew that's what React does.
