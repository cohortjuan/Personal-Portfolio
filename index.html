⭐ Featured

"Most habit apps are doing too much. This one is a checkbox with memory."

Tap a thing. It remembers. Get a streak going, watch the grid fill up. I built it to learn CSS Grid for real — not from a video.

The Hardest Part

Streak calculation broke when users skipped days then came back. I modelled the data as a Set of ISO date strings rather than a boolean array, then walked backwards from today. Switching the data structure halved the logic complexity.
